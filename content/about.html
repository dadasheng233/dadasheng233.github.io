你好，我是晚风

一个在前端和文字之间来回走的人。白天写界面，晚上写一些不一定有人看的东西。养了一只白猫，它现在住在页面左下角。

我在做什么

主要做 Web 前端：把设计稿变成可以点击的页面，也研究那些看起来不起眼、但会让产品变好的细节。喜欢原生的 HTML / CSS / JavaScript，喜欢读得懂的代码，也喜欢没有依赖的解决方案。

工作之外，我会拍照、读书、散步。相机里大多是街道、树影和猫；书架上大多是散文、设计和技术史。写博客是为了把散落的想法收拢起来，也为了确认自己真的想清楚了某件事。

把复杂的事情做简单，把简单的事情做久一点。

关于这个站点

这是一个静态博客：文章是 HTML 文件，样式和交互全部手写，构建脚本没有第三方依赖。页面里的白猫是一套 Live2D 模型，会呼吸、眨眼、转头，也会在你点它的时候说几句话。

视觉上参考了 Hexo NexT 的 Muse 主题和黑果小兵的博客，但布局、配色、代码和文案都是重新写的。小猫使用 Tororo 模型，加载器是开源的 live2d-widget。如果你要公开部署，请先确认模型素材的使用许可。
